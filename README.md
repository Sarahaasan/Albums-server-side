# Albums & Songs — Next.js

A simple **Next.js** project that fetches and displays albums and their songs using an external API.

## Features

* Fetch and display albums
* Display songs for each album
* Dynamic routes
* Loading UI
* Reusable components
* Tailwind CSS


## Server Components

The project uses **Next.js Server Components** to fetch data.

### Why Server Components?

* Better performance
* Less JavaScript sent to the browser
* Keep sensitive data on the server
* Fetch data directly on the server
* Access backend resources

Server Components are the default in the Next.js App Router.

## Technologies
